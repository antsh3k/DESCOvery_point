# DESCOvery_point
SME_analytics and matching with the most suitable PE funds

## Brief

Design a simple AI-powered tool that takes a company’s website URL as input, focusing primarily on small and mediumsized businesses (SMBs). The tool should analyze the website’s content to extract key information about the company, such as industry, location, size, and product offerings. Based on this analysis, it should generate a shortlist of private
equity funds that would be potential good buyers for the business.

Your task is to create a basic prototype of this tool, which you will demo virtually in your discussion with an interviewer, using an API of any LLM-based resource at your disposal (e.g., OpenAI’s GPT API) rather than a chat interface. We’re not concerned about the user interface—you can use low-code platforms, command-line interfaces, or any other method you prefer. The focus should be on functionality and effective use of the LLM API.
